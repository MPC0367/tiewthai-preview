# TiewThai · เที่ยวไทย — public preview

This site is the public preview of a private prototype of a Thailand hotel-booking app. It runs entirely in your browser with synthetic demo data only: nothing is booked or paid, no real hotel, person, payment or government benefit is involved, and anything you do stays in this browser's storage. The source code is private and is not published here; this repository holds only the built static files.

ตัวอย่างสาธารณะของระบบต้นแบบส่วนตัว ทำงานในเบราว์เซอร์ของคุณด้วยข้อมูลจำลองเท่านั้น ไม่มีการจองหรือชำระเงินจริง และข้อมูลของคุณอยู่ในเบราว์เซอร์นี้เท่านั้น ซอร์สโค้ดเป็นแบบส่วนตัวและไม่ได้เผยแพร่ที่นี่
